COMO PUBLICAR NA VERCEL:
1. Acesse vercel.com e faça login com GitHub
2. Clique em "Add New" > "Project" > "Browse" > selecione esta pasta
3. Clique em "Deploy"
4. Após deploy, vá em Settings > Domains > Add Domain
5. Adicione: guardiaoancestral.com.br e www.guardiaoancestral.com.br
6. A Vercel vai mostrar os DNS para configurar no Registro.br

DNS para colocar no Registro.br (após adicionar domínio na Vercel):
Tipo A: @ -> 76.76.21.21
CNAME: www -> cname.vercel-dns.com

Ou use os nameservers da Vercel se preferir.
